# تثبيت وتحديث NOVA Download Manager

## تنزيل البرنامج

ادخل إلى [صفحة الإصدارات الرسمية](https://github.com/Elsaadan/nova-download-manager/releases/latest)، واضغط على **Assets** وحمّل ملف التثبيت الخاص بالويندوز.

اسم ملف إصدار v0.15.4:

```text
NOVA_Setup_v0.15.4.exe
```

## خطوات التشغيل

1. حمّل ملف التثبيت `EXE` من **Assets**.
2. شغّل الملف واتبع خطوات التثبيت الظاهرة على الشاشة.
3. بعد اكتمال التثبيت، افتح NOVA Download Manager.
4. لاستخدام التقاط التحميلات من المتصفح، جهّز إضافة NOVA والاتصال مع Native Messaging المتوافق مع إصدارك.

## لو بتحدّث نسخة موجودة

**سيب `CLEAN START` بدون علامة صح** علشان تحتفظ بسجل مهام التحميل السابق. ما تحذفش بيانات البرنامج أو مجلد التحميلات أثناء التحديث العادي.

## التأكد من سلامة ملف التثبيت

بصمة `SHA-256` المنشورة لإصدار v0.15.4:

```text
AD4F5D7E32ACEC6BF31361CE26F26DB364B768DDB52ADC83E74DE5B00625A5B4
```

افتح PowerShell في نفس مجلد ملف التثبيت وشغّل:

```powershell
Get-FileHash ".\NOVA_Setup_v0.15.4.exe" -Algorithm SHA256
```

لو البصمة مختلفة، **ما تشغّلش الملف**.

## أسئلة مهمة

**أحمّل إيه من قسم Assets؟** ملف `NOVA_Setup_v0.15.4.exe`. الروابط `Source code (zip)` و`Source code (tar.gz)` بيضيفها GitHub تلقائيًا ومش هي ملف تثبيت NOVA.

**هل كل مواقع الفيديو شغالة؟** مش بالضرورة. التوافق بيختلف حسب الموقع وتسجيل الدخول وحقوق الاستخدام والتغييرات التقنية.
